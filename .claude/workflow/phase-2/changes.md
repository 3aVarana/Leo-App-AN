## Decisions as implemented

- D1: both repositories are `suspend`. `PreferencesRepository.save` never throws; `RoundHistoryRepository` errors propagate.
- D2: Preferences DataStore, `stringPreferencesKey("readerPreferences")` holding `LeoJson` text; file `files/datastore/leo.preferences_pb`; `ReplaceFileCorruptionHandler` (logs, empties). `load` catches `IOException`, `SerializationException`, `IllegalArgumentException`; `save` catches `IOException`, `SerializationException`. Tag `PreferencesRepository`, iOS messages.
- D3: UUID as lowercase TEXT, `finishedAt` as epoch millis INTEGER, `options`/`results` as JSON TEXT, raw values as String columns. `index` is quoted automatically by Room's generated SQL; no hand-written query touches it.
- D4: database opened lazily on first call on `ioDispatcher` (`openHelper.writableDatabase`), under a `Mutex`; `SQLiteException` or `IllegalStateException` logs the iOS message and switches to in-memory. Opener injected via the internal constructor. `setQueryCoroutineContext(ioDispatcher)`. No destructive migration.
- D5: `replaceRound` is one `@Transaction`: delete by id (cascade), insert round, insert answers.
- D6: version 1, `exportSchema = true`, schema JSON generated. No migration, no migration test; the rule is in the `RoundHistoryDatabase` KDoc.
- D7: as in the plan. KSP 2.3.12 + AGP 9.4.1 + Kotlin 2.2.10 worked with no version changes.

## Deviations and notes

- Added `IllegalStateException` to the fallback catch: Room reports "migration required but not found" (a store from a newer build) that way, and a failed open should never crash launch.
- `daoForTesting()` and `closeForTesting()` are `internal` members of `RoomRoundHistoryRepository`, used only by tests (answer row count, reopening the file).
- DataStore tests run under Robolectric (not plain JUnit as planned) only because `android.util.Log` is not available on the plain JVM; the DataStore itself is the real one on a temp file.
- Entities are public data classes (Room KSP does not cope well with `internal` members); the mapping functions are `internal`.
- `docs/learning/phase-2.md` not written, per the request.
- Nothing committed.
